# Rueda libre

Sitio web de **Rueda libre**, bicicletas en Medellín, y landing para la campaña **Rueda Nocturna**.

**Sitio publicado:** [https://mrgarcia3108.github.io/rueda-libre/]

## Contenido

- `index.html`, `paginas/`: sitio principal Bootstrap
- `nocturna/`: landing de Rueda Nocturna con Tailwind CSS.
- `pruebas/`: prototipo con Bootstrap.
- `bitacora.txt`: registro del proceso.

## Tecnologías

HTML5, CSS3, Bootstrap 5.3, Tailwind CSS 4 (CLI), Bootstrap Icons y GitHub Pages.

## Cómo ejecutarlo

Abre `index.html` en el navegador. Para editar la landing de `nocturna/`, ejecuta `npm install` y luego `npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch`.
